THE MECHANICS

让结构决定运动。

每个按键是独立的轴向质量—弹簧系统。键帽、轴心和弹簧长度都来自同一数值状态，拆解仅改变展示位置。

弹簧刚度

k = Gd⁴ / (8D³Nₐ)　 Fₛ = k(δ₀ + q)

d 为钢丝直径，D 为平均圈径，Nₐ 为有效圈数，G 为剪切模量，δ₀ 为预压。线径提高 10%，刚度约增加 46%。

动力学与段落感

mq̈ = F按压 + mg − Fₛ − cq̇ − F触片 − F摩擦

段落轴的凸轮改变簧片形变量 δℓ(q)，由储能 Uℓ = ½kℓδℓ² 对行程求导，得到阻力峰和回落。固定 0.25 ms 步长积分；顶部与触底止挡耗散碰撞能量。

两种控制方式

“按住试压”施加持续外力，由动力学计算位移。“保持位移”施加位置约束，松开后恢复自由回弹。曲线为准静态摩擦包络，读数为瞬时受力。

模型边界

这是可解释的实时机械近似，预设并非品牌手感复刻。键盘固定，长键采用卫星轴与连杆同步升降，不计算偏心倾斜、材料疲劳或电接触抖动。
